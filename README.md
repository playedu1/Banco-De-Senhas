# Banco De Senhas

[Repositório GitHub](https://github.com/playedu1/Banco-De-Senhas)

Uma ferramenta simples para guardar suas senhas com segurança, usando só uma senha principal.

## O que faz?
- Salva senhas de sites e apps criptografadas.
- Abre tudo com uma única senha mestre.
- Funciona no seu computador, sem internet.

## Como instalar
1. Baixe o repositório.
2. Abra a pasta e rode `python main.py`.

## Como usar
1. Na primeira vez, crie sua senha mestre.
2. Adicione senhas: nome do site, usuário e senha.
3. Para ver: digite a senha mestre.

**Nunca esqueça sua senha mestre!**
